## 📋 下一步操作

### 方式 A: 使用系统代理 (简单)

**Windows 设置代理**:
```powershell
# 在管理员 PowerShell 中运行
netsh winhttp set proxy 127.0.0.1:7890
```

或手动设置:
1. 设置 → 网络和 Internet → 代理
2. 手动设置代理: 开
3. 地址: 127.0.0.1
4. 端口: 7890
5. 保存

1. Profile → Proxy Servers → Add

3. 协议: HTTP
4. 添加规则: miniworld.exe → 使用此代理
