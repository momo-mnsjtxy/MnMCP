## 🐛 故障排查

### 问题 1: 桥接器无法连接 Minecraft

**症状**:
```
ERROR - ✗ 连接 Minecraft 服务器失败: Connection refused
```

**解决方案**:
1. 确认 Minecraft 服务器已启动
2. 检查端口 25565 是否被占用
3. 检查防火墙设置
4. 尝试使用 `telnet 127.0.0.1 25565` 测试连接

### 问题 2: 迷你世界无法连接

**症状**:
- 迷你世界显示"连接失败"
- 桥接器没有"新客户端连接"日志

**解决方案**:
1. 确认桥接器已启动
2. 检查端口 19132 是否被占用
3. 检查防火墙设置
4. 尝试使用 `telnet 127.0.0.1 19132` 测试连接

### 问题 3: 数据包解析错误

**症状**:
```
ERROR - 解析迷你世界数据包失败: ...
```

**解决方案**:
1. 检查迷你世界版本 (需要 1.55.0)
2. 查看详细错误日志
3. 可能需要更新协议解析代码

### 问题 4: 方块映射错误

**症状**:
- Minecraft 中显示错误的方块
- 日志显示"未找到方块映射"

**解决方案**:
1. 检查映射文件是否完整
2. 查看具体的方块 ID
3. 可能需要添加新的映射
