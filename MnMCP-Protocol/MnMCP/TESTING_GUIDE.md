## 📋 测试前准备

### 1. 环境要求

```bash
# Python 3.11+
python --version  # 应显示 3.11.x

# 依赖安装
pip install loguru cryptography msgpack pyyaml aiohttp websockets
```

### 2. 配置文件

```yaml
# config.yaml
mini:
  auth:
    uin: 0                    # 你的迷你世界账号
    passwd: ""                # 密码
    api_id: 110
    device_id: ""             # 设备ID
    xxtea_key: ""             # XXTEA密钥
  server:
    ip: 127.0.0.1
    port: 11155
    host_to_room_server: false
  send_log_to_chat: false

mc:
  ip: 127.0.0.1
  port: 25565
  username: ""
  version: "1.21.11"
  use_new_chunk_parser: true
  chunk_parse_thread: 4

# Phase 5 新增
server:
  mode: "dual"
  mini_port: 19132
  mc_port: 19133
  backend_port: 19134
  lan_ip: "auto"
  guid: 0

world:
  map_path: "./worlds/default"
  texture_path: "./textures"

debug: false
```

### 3. 地图准备

```bash
# 创建地图目录
mkdir worlds\default

# 可选：从迷你世界导出存档
# 或使用示例地图
```

## 🚨 常见问题

### Q1: 迷你世界无法连接

**检查**:
- 端口 19132 是否开放
- 防火墙是否允许
- LAN IP 是否正确

### Q2: Minecraft 连接失败

**检查**:
- 端口 19133 是否开放
- Minecraft 版本是否为 1.20.6
- 后端服务是否运行

### Q3: 区块不显示

**检查**:
- 地图路径是否正确
- 地图文件是否存在
- 区块解析器是否正常
